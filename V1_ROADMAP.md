# Version 1.0 Roadmap

## Current: Version 1.0.0

### Release Status
- **Phase:** Production Release
- **Target:** Q2 2026
- **Status:** Ready for submission

### Completed Features
- Scanner discovery
- Document scanning (PDF, JPEG, PNG, TIFF)
- Page preview and management
- PDF merge functionality
- Custom file naming
- Auto-rotate
- Dark/Light themes
- Windows 11 Mica effect
- Multi-language support (25)
- Settings persistence

## Known Limitations

### High Priority
- Some older scanners not supported
- Network scanner support varies
- Limited OCR capabilities

### Medium Priority
- Cloud storage not integrated
- No mobile companion app
- No document search

### Low Priority
- Limited annotation tools
- No batch rename

## Future Versions

### Version 1.1.0 (Planned)
- Improved network scanner support

### Version 1.2.0 (Planned)

- End of support: October 2025
