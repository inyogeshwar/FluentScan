# Beta Release Plan

## Beta Goals

1. Test core scanning functionality
2. Validate compatibility with various scanners
3. Gather user feedback
4. Identify bugs before public release

## Beta Channels

### Channel 1: GitHub Releases
- Package: MSIX
- Audience: Tech enthusiasts, developers
- Update: Manual

### Channel 2: Microsoft Store (Insider)
- Package: MSIX via Partner Center
- Audience: Limited testers
- Update: Store push

## Beta Timeline

### Week 1-2: Internal Testing
- [ ] Verify all features work
- [ ] Test on multiple Windows versions
- [ ] Test with various scanners
- [ ] Fix critical bugs

### Week 3: Beta 1
- [ ] Release to 5-10 testers
- [ ] Collect feedback
- [ ] Fix reported issues

### Week 4: Beta 2
- [ ] Expand to 20-50 testers
- [ ] Final bug fixes
- [ ] Performance optimization

### Week 5: Release Candidate
- [ ] Final testing
- [ ] Documentation complete
- [ ] Store listing ready

### Week 6: Public Release
- [ ] Submit to Store
- [ ] Publish on GitHub

## Beta Criteria

### Must Pass
- Scanner discovery works
- Scan completes successfully
- PDF export works
- App doesn't crash

### Should Pass
- Dark/Light themes work
- Settings persist
- Multi-page merge works

### Nice to Have
- Network scanner support
- All 25 languages fully tested
