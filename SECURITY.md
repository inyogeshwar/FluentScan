# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.0.x | Yes |

## Reporting Security Issues

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them by sending an email to: yogeshwar853202@gmail.com

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## Security Considerations

### Data Handling
- All scanned documents are stored locally
- No cloud upload of document content
- Settings stored in local AppData
- Logs contain diagnostic information only

### Network
- No network calls except for:
  - App Center analytics (optional, can be disabled)
  - GitHub links for external resources
- No sensitive data transmitted

### Permissions
- Scanner access (required for scanning)
- File system access (required for saving)
- Camera access (optional, for live scanning)

## Best Practices

1. Keep Windows updated
2. Download from official sources only
3. Review privacy settings
4. Report suspicious behavior
