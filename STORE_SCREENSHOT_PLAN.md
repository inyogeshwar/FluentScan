## Technical Requirements

### Format
- Format: PNG
- Aspect ratio: 16:9
- Minimum: 1920x1080
- Maximum: 3840x2160

### File Size
- Each screenshot: 2MB max
- Total submission: 15MB max

### Content Guidelines
- Show actual app UI (no mockups)
- Include Windows chrome
- Use default theme for first 5
- Highlight key features
- No text overlays (optional: brief labels)

## Screenshot Descriptions for Store

### 1. Main Navigation
> Modern app window showing NavigationView with scan options, page list, and settings navigation items.

### 2. Scanner Selection
> Dropdown or list showing available scanners with clear selection UI.

### 3. Scan Options Panel
> Options panel with resolution (100-600 DPI), color mode, and page size selectors.

### 4. Page Preview
> Thumbnail grid of scanned pages with selection and page numbers.

### 5. Export Options
> Save dialog showing PDF, JPEG, PNG, TIFF format options with naming pattern.

### 6. Settings
> Settings page showing save location, default scan options, and theme toggle.

### 7. Dark Mode
> Same as screenshot 1 but showing dark theme with proper contrast.
