# Brand Guidelines

## Logo Usage

### Primary Logo
- Use FluentScan Logo from `FluentScan/Assets/contrast-standard/`
- Dark background: Use contrast-black variant
- Light background: Use contrast-white variant
- No modifications or color changes

### Minimum Sizes
- Print: 20mm width
- Digital: 44px width
- App icon: 44x44 pixels

### Clear Space
- Maintain equal space to logo height on all sides
- Never overlap with other elements

## Typography

### Primary Font
- Windows UI font (Segoe UI)
- Fallback: system default

### Style Guide
- Headings: Bold, BaseTextBlockStyle
- Body: Regular, BodyTextBlockStyle
- Caption: Light, CaptionTextBlockStyle

## Colors

### Primary Color
- SystemAccentColor (Windows theme)
- Use ThemeResource bindings for theming

### Backgrounds
- Light: LayerFillColorDefaultBrush
- Dark: LayerFillColorDefaultBrush (dark variant)
- Mica: Applied on Windows 11 via BackdropMaterial

### Text
- Light mode: #000000 (87% primary)
- Dark mode: #FFFFFF (87% primary)

## App Name

### Usage
- "FluentScan" - official name
- "Fluent Scan" - alternate (if needed)
- No abbreviation (e.g., FS)

### Capitalization
- Title case in UI
- Sentence case in body text

## Imagery

### Screenshots
- Use actual app UI
- Show clean, default theme
- Include window chrome
- No annotations or highlights
