# Contributing to FluentScan

Thank you for your interest in contributing to FluentScan!

## How to Contribute

### Reporting Bugs
1. Check existing issues to avoid duplicates
2. Use the bug report template
3. Include:
   - Clear description
   - Steps to reproduce
   - Expected vs actual behavior
   - Windows version
   - App version

### Suggesting Features
1. Search existing feature requests
2. Use the feature request template
3. Explain the use case
4. Consider impact on users

### Pull Requests
1. Fork the repository
2. Create a feature branch
3. Make changes with clear commits
4. Update documentation if needed
5. Submit with descriptive PR

## Development Setup

### Prerequisites
- Visual Studio 2022 Community or higher
- Windows SDK 10.0.26100.0
- .NET 8.0 SDK

### Build Instructions
```
1. Open FluentScan.sln in Visual Studio
2. Set FluentScan.Package as startup project
3. Build solution (Debug or Release)
4. Run on local machine or device
```

## Code Style

- Follow existing code patterns
- Use MVVM architecture
- Prefer async/await over blocking calls
- Add logging for significant operations
