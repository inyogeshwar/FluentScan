# Changelog

All notable changes to FluentScan will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0.0] - 2026-05-13

### Added
- Initial release of FluentScan
- Scanner discovery and selection
- Document scanning with multiple page support
- PDF generation with merge capability
- Image rotation and basic editing
- Multi-language support (25 languages)
- Windows 10/11 compatibility
- Dark/Light theme support
- Windows 11 Mica backdrop effect
- Custom file naming patterns

### Features
- Scan to PDF, JPEG, PNG, TIFF
- Batch scanning with page preview
- Auto-rotation based on content
- Configurable resolution (100-600 DPI)
- Color, Grayscale, Black & White modes
- Automatic document feeder detection

### Known Limitations
- Some older scanners may not be compatible
- Network scanner support varies by manufacturer
- Not all scanner features accessible via Windows API
