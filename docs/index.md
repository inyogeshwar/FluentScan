## What is FluentScan?

FluentScan allows you to scan documents using your connected scanners and create PDF files, merge multiple pages, and organize your scans efficiently.

## Key Features

- **Universal Scanner Support** - Works with most Windows-compatible scanners
- **Multi-format Output** - Save as PDF, JPEG, PNG, or TIFF
- **Page Merging** - Combine multiple scans into one document
- **Modern UI** - Windows 11 Fluent Design with Mica effect
- **Multi-language** - Supports 25 languages
