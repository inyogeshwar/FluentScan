# FluentScan Features

## Scanning

### Scanner Management
- Automatic scanner discovery
- Manual scanner selection
- Scanner status indicators
- Support for multiple scanners

### Scan Settings
| Setting | Options |
|---------|---------|
| Color Mode | Color, Grayscale, Black & White |
| Resolution | 100, 150, 200, 300, 600 DPI |
| Page Size | Letter, Legal, A4, Auto |
| Brightness | -50 to +50 |
| Contrast | -50 to +50 |

## Document Management

### Supported Formats
- **PDF** - Single or multi-page
- **JPEG** - High quality images
- **PNG** - Lossless compression
- **TIFF** - Multi-page professional format

### Organization
- Custom file naming patterns
- Auto-save to configured folder
- Batch operations support
- Recent scans quick access

## PDF Features

### Creation
- Single-page PDF
- Multi-page PDF from multiple scans
- Merge existing scans into new PDF

### Options
- PDF/A archive format option
- Compression level selection
- OCR-ready settings

## Image Editing

### Available Tools
- Rotate (90°, 180°, 270°)
- Auto-rotate based on content
- Crop
- Adjust brightness/contrast

## User Interface

### Design
- Windows 11 Fluent Design
- Mica backdrop effect (Win11)
- Adaptive layout (compact/expanded)
- Keyboard navigation support

### Themes
- Light mode
- Dark mode
- System theme following

### Languages
- English (default)
- 24 additional languages supported

## Advanced Features

### Automation
- Default scan settings
- Auto-rotate documents
- Auto-save to folder
- Custom naming patterns

### Integration
- Windows Share target
- File picker integration
- Clipboard support
