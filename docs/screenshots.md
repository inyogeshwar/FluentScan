# FluentScan Screenshots

## Store Screenshots

The following screenshots are recommended for Microsoft Store submission:

### Required Images
| Image | Size | Purpose |
|-------|------|---------|
| Store Logo | 50x50 | Store listing icon |
| Small Tile | 71x71 | Small window |
| Wide Logo | 310x150 | Wide banner |
| Large Tile | 310x310 | Start menu |
| Splash Screen | 620x300 | Launch screen |

### Screenshot Requirements
- Minimum 5 screenshots required
- Recommended: 8-10 screenshots
- Resolution: 1920x1080 or higher
- Format: PNG

## Capture Instructions

### Windows 11
1. Press Win+Shift+S for Snip & Sketch
2. Select area
3. Save as PNG

### Tips
- Use default Windows theme
- Include window chrome
- Show Fluent Design elements
- Highlight key features

## Organization

Store screenshots should tell a story:
1. Introduction/landing
2. Scanner selection
3. Scan options
4. Preview/edit
5. Save/export
