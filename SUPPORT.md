# Support for FluentScan

## Getting Help

### Frequently Asked Questions
**Q: Does FluentScan work with my scanner?**
A: FluentScan uses Windows built-in scanner APIs. Most scanners compatible with Windows will work.

**Q: Can I scan multiple pages into one PDF?**
A: Yes, use the merge feature to combine multiple scans.

**Q: Where are my scanned documents saved?**
A: By default, Documents\FluentScan. Can be changed in settings.

**Q: How do I change the scan quality?**
A: Go to Scan Options before scanning to adjust resolution and color mode.

### Common Issues

**Scanner not found:**
- Ensure scanner is powered on
- Check Windows Settings > Devices > Scanners
- Try reconnecting the scanner

**PDF not saving:**
- Check storage space
- Verify folder permissions
- Try a different save location

**App crashes on startup:**
- Check Windows Event Viewer for details
- Try reinstalling the app
- Ensure Windows is up to date
