# FluentScan Logo Design Prompts

Use these prompts to generate new logos for FluentScan. Each prompt is designed for AI image generation tools or designer brief.

---

## Overview

**Purpose:** Replace 8 inherited Scanner logo SVGs with FluentScan branding

**Requirements:**
- 4 theme variants: standard, black, white, high-contrast
- 2 size variants: full (Logo.svg) and small (Logo small.svg)
- SVG format, scalable, transparent background
- No text - purely graphical for internationalization

---

## Theme: contrast-standard (Default System Theme)

### Prompt: Full Size Logo (Logo.svg)

```
Create a modern, minimalist logo icon for a Windows scanner app called "FluentScan".

Design requirements:
- Vector format (SVG), 450x450 viewBox
- Simple, clean icon representing document scanning
- Use a document/page icon combined with a subtle scan line or lens element
- Color palette: Dark grays (#383f45 to #6a747b) with a subtle accent blue (#0078D4)
- No text - icon only
- Transparent background
- Fluent Design language - simple geometric shapes, slight rounded corners
- Modern, professional appearance suitable for Windows 11

Icon should suggest:
- Document scanning
- Digital document creation
- Simplicity and ease of use
- Windows ecosystem integration
```

### Prompt: Small Size Logo (Logo small.svg)

```
Create a compact, simplified version of a FluentScan app icon.

Design requirements:
- Vector format (SVG), 44x44 viewBox
- Simplified version of a document scanning icon
- Bold, readable at small sizes (16px minimum)
- Same color palette as full logo: grays (#4c545b to #606971) with accent
- Transparent background
- Single geometric shape - document outline with scan line
- No text or fine details
- Works on both light and dark backgrounds
```

## Alternative Design Concepts

### Concept A: "F" Monogram

```
Create an "F" letterform icon for FluentScan app.

Design:
- Bold, geometric "F" letter
- Document shape integrated into the F (vertical stroke is document)
- Single accent color with grayscale
- Scalable to 16px
- Works in all themes (adjust colors)
```

### Concept B: Document + Scan Line

```
Minimalist document scanner icon.

Design:
- Simple rectangle representing paper/document
- Horizontal line or beam across document (scan element)
- Optional: small lens or focus circle
- No detailed scanner device - abstract representation
- Very clean, modern
```

### Concept C: Stack of Documents

```
Document stack icon representing multi-page scanning.

Design:
- 2-3 stacked rectangles (documents)
- Slight offset to show depth
- Optional scan beam or checkmark
- Represents "batch scanning" feature
```

### Concept D: Camera/Scan Hybrid

```
Camera-like icon suggesting document capture.

Design:
- Rectangle with rounded corners (document shape)
- Inner rectangle or viewfinder element
- Optional flash/scan indicator
- Suggests "capture" or "scan" action
```

## Color Reference

### Standard Theme
- Primary: #383f45 (dark gray)
- Secondary: #606971 (medium gray)
- Accent: #0078D4 (Windows blue)

### Dark Theme
- Primary: #899097 (light gray)
- Secondary: #b3b3b3 (lighter gray)
- Accent: #60CDFF (bright blue)

### White Theme
- Primary: #383f45 (dark gray)
- Secondary: #5e676e (medium gray)
- Accent: #0078D4 (Windows blue)

### High Contrast
- Primary: #000000 or #FFFFFF
- No secondary or accent - pure contrast
